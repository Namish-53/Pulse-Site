# Pulse-Site-12 🚀

A custom new tab page built by **Namish** as part of the Stardance mission.  
This project features a real-time digital clock, date display, and a quick‑launch dashboard with links to my favorite sites.

---

## ✨ Features
- Live clock that updates every second ⏰  
- Current date display 📅  
- Neon‑styled custom UI with gradient background 🌌  
- Hover animations for interactive feel ⚡  
- Quick‑launch dashboard buttons (YouTube, Spotify, Gmail, GitHub) 🎯  
- Footer credit line: *Made by Namish ✨*
